## 🎨 Design Features

### Visual Design
- **Background**: Forest/nature-inspired bokeh effect with dark overlay
- **Color Palette**: 
  - Primary: Gold (#e8d4b8)
  - Secondary: Dark semi-transparent backgrounds
  - Accent Colors: Orange, Coral, Yellow, Beige, Sage, Olive, Teal
- **Typography**: Elegant italic fonts for headings, clean sans-serif for body text
- **Layout**: Responsive mobile-first design

### Sections
1. **Header** - Tagline "ika kasai na sina"
2. **Couple Names** - "Tupe at Eula" with proper styling
3. **Invitation Message** - Main invitation with date and location
4. **Event Details** - Ceremony and reception information with times
5. **Love Story** - Sections detailing how the couple met and their journey
6. **Dress Code** - Formal attire guidelines (Modern Filipiniana, Barong Tagalog, etc.)
7. **Color Theme** - Visual representation of wedding colors
8. **RSVP Information** - Instructions for responding to the invitation
9. **FAQ Section** - Contact information and questions

## 🛠 Customization

To modify the site, edit `index.html`:

- **Update Names**: Change "Tupe" and "Eula"
- **Change Dates/Times**: Modify event schedule
- **Adjust Colors**: Modify color hex codes in the `<style>` section
- **Update Venues**: Change ceremony and reception locations
- **Add Images**: Include couple photos or gallery
